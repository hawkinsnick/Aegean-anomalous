# Aegean Anomalous Inscriptions

A neutral quarantine and comparison corpus for Aegean inscriptions/objects whose script classification, writing status, or relationship to established corpora is disputed.

**This repository does not posit an “Aegean anomalous language” or a single anomalous writing system.** Inclusion means that an object is useful for controlled comparison because its classification is contested.

Initial research anchors include the Arkalochori Axe and Malia Altar Stone. Phaistos remains a separate project and is cross-referenced rather than duplicated as an anomalous-script assertion.

See `research/admission-policy.json`, `research/pre-expert-maximum.json`, and `ai-skill/SKILL.md`.


## Offline corpus browser
Run `python scripts/build_corpus_browser.py` to generate `workbench/corpus-browser.html`. It searches only files explicitly admitted by `research/browser-sources.json`. Browser admission requires rights/provenance review; never recursively ingest restricted or raw upstream material. Display does not establish decipherment, source independence, or expert validation.
